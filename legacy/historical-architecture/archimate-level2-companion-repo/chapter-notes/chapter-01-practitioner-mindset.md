# Chapitre 1 — État d’esprit Practitioner

## Objectif
Passer d’une logique “je reconnais le langage” à une logique “je l’applique correctement”.

## Ce qu’il faut comprendre
À ce niveau, on attend de toi que tu saches :
- lire un besoin de communication ;
- choisir un angle de vue ;
- sélectionner les éléments utiles ;
- éviter de surcharger le modèle ;
- justifier pourquoi une proposition est meilleure qu’une autre.

## Piège majeur
Croire qu’un modèle est meilleur parce qu’il montre plus de choses.
