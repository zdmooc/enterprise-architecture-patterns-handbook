# Cadre d’usage

Ce dépôt est un support d’étude **original**.

Il :
- s’appuie sur les thèmes publics de la certification ArchiMate Practitioner ;
- reformule les notions ;
- ajoute des scénarios et exercices originaux.

Il ne reproduit pas :
- les questions officielles exactes ;
- les contenus protégés d’examens blancs ;
- les transcriptions de formations commerciales.
