# Checklist de revue de modèle

## Pertinence
- [ ] la vue répond à une vraie question
- [ ] l’audience est identifiable
- [ ] le niveau de détail est cohérent

## Sémantique
- [ ] les éléments choisis sont corrects
- [ ] les relations sont valides
- [ ] association n’est pas utilisée par paresse

## Lisibilité
- [ ] la vue reste compréhensible
- [ ] elle n’est pas surchargée
- [ ] le message principal se voit rapidement
