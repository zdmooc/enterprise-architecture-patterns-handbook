# Récapitulatif 1 page

## ArchiMate niveau 2 en très court
- penser d’abord audience et message ;
- choisir la vue la plus utile ;
- rester sémantiquement précis ;
- éviter la surcharge ;
- savoir justifier pourquoi une option est meilleure.

## Réflexe examen
Chercher :
- qui lit ?
- pour comprendre quoi ?
- avec quel niveau de détail ?
