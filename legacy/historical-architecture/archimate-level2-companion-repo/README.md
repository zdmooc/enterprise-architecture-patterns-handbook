# ArchiMate niveau 2 — Dépôt compagnon de préparation

Dépôt de préparation en français pour **ArchiMate 3 Practitioner / Part 2**.

## Positionnement
Ce dépôt sert à :
- passer d’une logique de connaissance à une logique d’**application** ;
- traiter des **scénarios** de modélisation ;
- choisir la **vue la plus utile** ;
- sélectionner les bons éléments et les bonnes relations ;
- utiliser correctement le format **open book**.

## Ce dépôt contient
- notes Practitioner ;
- méthode de lecture de scénario ;
- guides de sélection de vue ;
- patterns de bonne / mauvaise réponse ;
- banque de scénarios ;
- examens blancs maison ;
- plan quotidien de révision ;
- section entretien / mission.
