# Réutiliser ArchiMate Practitioner en entretien

## Ce que tu peux dire
Le niveau Practitioner m’entraîne à produire la bonne vue pour la bonne audience, en gardant le bon niveau de détail et en expliquant pourquoi une modélisation est plus pertinente qu’une autre.

## Exemples
- vue sponsor pour une migration ;
- vue applicative pour des dépendances ;
- vue technologie pour l’hébergement cible ;
- vue transformation pour des lots de migration.
