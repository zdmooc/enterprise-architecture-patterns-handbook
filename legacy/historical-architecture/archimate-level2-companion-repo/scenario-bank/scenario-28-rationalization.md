# Scénario 28 — Rationalization (variante 3)

## Contexte
Une organisation veut repérer les redondances applicatives et préparer une rationalisation.

## Question
Quelle vue ou approche de modélisation est la plus appropriée ?

## Réponse de travail
Choisir une vue mettant en évidence services, composants et recouvrements, sans surcharge inutile.

## Pourquoi
La vue doit aider à voir les doublons.

## Ce qui rendrait d’autres réponses plus faibles
- vue trop chargée ;
- vue hors audience ;
- vue avec trop de détails techniques ;
- vue sémantiquement faible ;
- vue oubliant la transformation ou le cross-layer si nécessaire.
