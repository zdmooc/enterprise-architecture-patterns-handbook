# Scénario 31 — Security Concerns (variante 1)

## Contexte
Une équipe sécurité veut comprendre quelles applications exposent un service sensible et comment elles sont supportées.

## Question
Quelle vue ou approche de modélisation est la plus appropriée ?

## Réponse de travail
Choisir une vue ciblée montrant les applications, services concernés et dépendances pertinentes.

## Pourquoi
La vue doit être lisible et orientée risque.

## Ce qui rendrait d’autres réponses plus faibles
- vue trop chargée ;
- vue hors audience ;
- vue avec trop de détails techniques ;
- vue sémantiquement faible ;
- vue oubliant la transformation ou le cross-layer si nécessaire.
