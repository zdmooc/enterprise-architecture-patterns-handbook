# Scénario 18 — Migration Lots (variante 3)

## Contexte
Un comité de transformation veut visualiser les lots de migration d’un patrimoine applicatif vers une cible industrielle.

## Question
Quelle vue ou approche de modélisation est la plus appropriée ?

## Réponse de travail
Choisir une vue implementation & migration mettant en évidence work packages, transitions et trajectoire.

## Pourquoi
La vue doit aider à piloter la transformation.

## Ce qui rendrait d’autres réponses plus faibles
- vue trop chargée ;
- vue hors audience ;
- vue avec trop de détails techniques ;
- vue sémantiquement faible ;
- vue oubliant la transformation ou le cross-layer si nécessaire.
