# Scénario 37 — Business Value Chain (variante 2)

## Contexte
Un architecte métier veut relier capacités, processus et services afin d’expliquer une cible organisationnelle.

## Question
Quelle vue ou approche de modélisation est la plus appropriée ?

## Réponse de travail
Choisir une vue business/strategy ou cross-layer légère, selon le message exact.

## Pourquoi
La vue doit rester compréhensible pour un public métier.

## Ce qui rendrait d’autres réponses plus faibles
- vue trop chargée ;
- vue hors audience ;
- vue avec trop de détails techniques ;
- vue sémantiquement faible ;
- vue oubliant la transformation ou le cross-layer si nécessaire.
