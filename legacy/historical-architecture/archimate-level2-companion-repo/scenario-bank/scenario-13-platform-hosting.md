# Scénario 13 — Platform Hosting (variante 3)

## Contexte
Une équipe plateforme veut comprendre sur quel socle technologique tournent des composants applicatifs critiques.

## Question
Quelle vue ou approche de modélisation est la plus appropriée ?

## Réponse de travail
Choisir une vue technology ou cross-layer montrant nodes, system software et dépendances d’hébergement.

## Pourquoi
Le besoin est l’infrastructure de support.

## Ce qui rendrait d’autres réponses plus faibles
- vue trop chargée ;
- vue hors audience ;
- vue avec trop de détails techniques ;
- vue sémantiquement faible ;
- vue oubliant la transformation ou le cross-layer si nécessaire.
