# Drill 01 — Business / Application / Technology

## Objectif
Relier les couches principales sur un mini-cas.

## Cas
Une entreprise traite des sinistres via une application décisionnelle déployée sur une plateforme cible.

## Travail
1. Définis un rôle métier.
2. Définis un processus métier.
3. Définis un composant applicatif.
4. Définis un service applicatif.
5. Définis un nœud technologique.
6. Relie-les de façon cohérente.
