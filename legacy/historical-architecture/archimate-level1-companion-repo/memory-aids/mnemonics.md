# Aides mémoire

## Business / Application / Technology
- métier = ce qu’on fait
- application = ce qui supporte
- technologie = où / avec quoi ça tourne

## Serving / Access
- serving = rend un service
- access = lit, écrit ou manipule un objet passif

## Composition / Aggregation
- composition = lien fort
- aggregation = regroupement plus souple
