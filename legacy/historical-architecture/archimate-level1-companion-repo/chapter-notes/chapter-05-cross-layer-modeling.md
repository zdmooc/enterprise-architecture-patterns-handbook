# Chapitre 5 — Modélisation cross-layer

## Objectif
Comprendre les dépendances entre métier, application et technologie.

## Exemples
- un service métier peut être supporté par un service applicatif ;
- un service applicatif peut s’appuyer sur un service technologique ;
- une transformation peut être représentée via implementation & migration.

## Piège
Croire qu’il faut modéliser chaque couche isolément.
