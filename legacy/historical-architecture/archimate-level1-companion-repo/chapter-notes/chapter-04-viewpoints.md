# Chapitre 4 — Viewpoints

## Objectif
Comprendre qu’une vue sert un besoin de communication.

## Idée clé
Le bon diagramme n’est pas le plus complet.
C’est celui qui répond au bon stakeholder avec le bon niveau de détail.

## Réflexes
- définir l’audience ;
- définir le message ;
- choisir les éléments minimaux ;
- éviter la surcharge.

## Piège
Construire une vue techniquement riche mais illisible pour son public.
