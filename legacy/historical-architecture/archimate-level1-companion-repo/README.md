# ArchiMate niveau 1 — Dépôt compagnon de préparation

Dépôt de préparation en français pour **ArchiMate 3 Foundation / Part 1**.

## Positionnement

Ce dépôt sert à :
- comprendre la structure du langage ArchiMate ;
- apprendre les couches et concepts de base ;
- reconnaître les relations principales ;
- raisonner avec les viewpoints ;
- s’entraîner avec des QCM, drills et mini-cas.

## Ce dépôt contient

- notes détaillées chapitre par chapitre ;
- synthèses sur les couches ;
- pense-bêtes sur les relations ;
- drills de modélisation ;
- banque QCM ;
- examens blancs maison ;
- plan quotidien de révision ;
- aides mémoire ;
- section entretien / mission.

## Ce dépôt ne contient pas

- les questions officielles exactes ;
- le contenu protégé recopié d’un cours payant ;
- des dumps d’examen.

## Démarrage conseillé

1. `docs/00-overview.md`
2. `chapter-notes/chapter-01-structure-du-langage.md`
3. `layers/01-business-layer.md`
4. `relations/01-core-relations.md`
5. `mcq/question-bank-mcq.md`

## Résultat attendu

À la fin du dépôt, tu dois être capable de :
- expliquer ce qu’est ArchiMate ;
- distinguer couches, éléments et relations de base ;
- comprendre l’intérêt des viewpoints ;
- lire et produire des mini-modèles simples ;
- préparer l’examen Foundation.
