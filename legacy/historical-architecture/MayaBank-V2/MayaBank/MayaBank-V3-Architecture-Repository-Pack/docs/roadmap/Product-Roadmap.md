# Product Roadmap

## 1. Objet

Cette roadmap décrit la trajectoire de maturité globale du dépôt MayaBank.

## 2. Trajectoire

### V1 — socle crédible
- structure complète du dépôt
- vision
- HLD principal
- LLD global + providers
- premiers workloads
- gouvernance fondatrice
- FinOps initial

### V2 — extension Data/IA et industrialisation initiale
- intégration Data/IA dans la vision et le HLD
- premiers patterns Data/IA
- observabilité baseline
- Ansible / pipelines documentés
- runbooks enrichis
- sécurité de base

### V3 — posture architecte senior outillée
- Architecture Repository & Tooling
- bloc TOGAF / ArchiMate / repository d’architecture
- modélisation de référence
- design authority plus explicite
- traçabilité architecture → backlog
- GitOps plus lisible côté architecture

### V4 — enterprise-ready
- hardening
- conformité
- IAM mature
- audit logging
- mapping complet OKD → OpenShift enterprise
- gouvernance consolidée

## 3. Résultat attendu
À terme, MayaBank doit être :
- lisible ;
- crédible ;
- réutilisable ;
- pilotable ;
- suffisamment structuré pour être repris sans contexte oral.
