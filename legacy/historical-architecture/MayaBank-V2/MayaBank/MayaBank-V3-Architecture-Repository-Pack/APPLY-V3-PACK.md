# Apply V3 Pack

Ce pack est prévu pour être **décompressé à la racine du dépôt MayaBank**.

## Étapes recommandées

1. Décompresser le ZIP dans le répertoire local `MayaBank`
2. Vérifier l’état Git :
   - `git status`
3. Relire en priorité :
   - `README.md`
   - `docs/hld/HLD-Architecture-Repository-and-Tooling.md`
   - `docs/governance/Architecture-Toolchain.md`
   - `docs/roadmap/Sprint-Plan.md`
4. Commiter :
   - `git add .`
   - `git commit -m "V3 architecture repository and tooling"`
   - `git push`
