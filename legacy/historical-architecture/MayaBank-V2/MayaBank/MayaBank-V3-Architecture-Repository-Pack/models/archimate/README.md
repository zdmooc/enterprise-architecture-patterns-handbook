# ArchiMate Models Repository

## 1. Objet

Ce répertoire accueille les **modèles ArchiMate** de MayaBank.

Il sert de point d’entrée pour pratiquer la modélisation d’architecture de manière progressive, versionnée et traçable.

## 2. Structure proposée

- `views/` : vues ArchiMate
- `catalogs/` : catalogues d’objets
- `exchange/` : exports / formats d’échange
- `notes/` : conventions de modélisation

## 3. Premier objectif

Produire progressivement :
- une vue contexte globale MayaBank ;
- une vue platform ;
- une vue shared services ;
- une vue Data/IA ;
- une vue trajectoire OKD → OpenShift enterprise.

## 4. Règle

La modélisation ne remplace pas les HLD/LLD.  
Elle complète la lisibilité du repository d’architecture.
