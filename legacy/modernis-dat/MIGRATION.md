# Historical repository preservation

All 62 Git-tracked source blobs were copied byte-for-byte from the pinned historical commit(s). The exact SHA and original modes are in [source-map.json](source-map.json). The original repository licenses remain in their original relative paths. Git history, issues, tags and repository settings are not imported. This is file preservation only, not proof of runtime, successful builds, or tests. Do not delete archived sources until every SHA is verified after merge on main.
