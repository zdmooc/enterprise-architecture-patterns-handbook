# Checklist conformité (exemple)

## Avant MEP
- [ ] DAT à jour (version taggée)
- [ ] ADR validés pour choix structurants
- [ ] Matrice de flux validée SSI + Réseau
- [ ] NFR validés + plan perf exécuté
- [ ] Runbooks (incident/rollback/DRP) disponibles
- [ ] Observabilité : dashboards + alerting en place
- [ ] Sécurité : scans images OK + secrets gérés correctement

## Après MEP (T+7 jours)
- [ ] Revue prod (écarts vs DAT)
- [ ] Post-mortem si incident
- [ ] Ajustements capacity/HPA si nécessaire
