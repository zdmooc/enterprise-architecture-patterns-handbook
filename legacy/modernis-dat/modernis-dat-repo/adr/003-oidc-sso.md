# ADR-003 — IAM/SSO via OIDC
- **Statut** : Accepted
- **Date** : 2025-12-18
- **Décideurs** : SSI / Architecture
- **Contexte** : Unifier l’authentification, gérer les groupes/roles, tracer les accès.
- **Décision** : Standardiser l’accès via OIDC (IAM entreprise ou Keycloak) + mapping groupes → rôles.
- **Conséquences** : Simplification SSO, traçabilité, intégration API gateway.
