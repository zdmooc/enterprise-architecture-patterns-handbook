# ADR-002 — API Management / Gateway
- **Statut** : Proposed
- **Date** : 2025-12-18
- **Décideurs** : Architecture / SSI / Métier
- **Contexte** : Exposition d’API internes/externes, besoin de politiques sécurité, quotas, portail développeur, observabilité.
- **Décision** : Mettre en œuvre un socle API Management (ex : IBM API Connect, Apigee, Kong Enterprise) — choix final via CDC/AO.
- **Options** : IBM APIC, Apigee, Kong, WSO2…
- **Conséquences** : Gouvernance API, standardisation authn/authz, réduction risques.
